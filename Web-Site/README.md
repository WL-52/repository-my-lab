# Сайт-портфолио

Простой статический сайт с резюме на русском и английском.
Деплой автоматический — на каждый push в `main` GitHub Actions публикует
сайт на GitHub Pages (workflow `.github/workflows/pages.yml` в корне репо).

## Важно: добавить фото

Перед публикацией скопируйте **своё фото** в файл:

```
Web-Site/assets/photo.jpg
```

Фото Сергея должно быть в формате JPG (можно PNG, но тогда переименуйте расширение
в `index.html` в `src="assets/photo.png"`).

## Структура

```
Web-Site/
├── index.html       — главная страница с фото, проектами и навыками
├── resume.html      — резюме на RU и EN, кнопка «Печать»
└── assets/
    ├── style.css    — стили (простые, как у студента)
    └── photo.jpg    — ВАШЕ ФОТО (добавить вручную!)
```

## Локальный просмотр

```bash
cd Web-Site
python3 -m http.server 8000
# открыть http://localhost:8000
```
